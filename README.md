# Saydown

全本機的 Windows 語音輸入工具，用法和 Typeless 一樣：按右 Alt 說話，放開後自動辨識、修稿，貼到游標所在位置。語音與文字都不會離開這台電腦。

- 版本：1.1.3
- 作者：林凌禕
- 授權：MIT

## 需要的環境

- Windows 10／11（64 位元）
- NVIDIA 顯示卡（建議 8 GB 以上顯示記憶體）：**可選**。有的話語音辨識用 faster-whisper large-v3 在 GPU 上執行，又快又準；沒有的話自動改用 CPU 和較小的模型，見[沒有顯示卡的電腦](#沒有顯示卡的電腦)
- [Ollama](https://ollama.com)，並先下載修稿模型：`ollama pull qwen3.5:9b`（設定視窗可換成其他模型）：**可選**，不修稿就不需要
- 第一次啟動會自動下載語音辨識模型（有顯示卡約 3 GB，沒有約 0.5 GB），之後離線也能用

## 安裝

到 [Releases](https://github.com/allllen001/saydown/releases) 下載安裝檔執行即可，不需要系統管理員權限。每一版都有兩個安裝檔：

| 安裝檔 | 大小 | 給哪種電腦 |
|---|---|---|
| `Saydown-Setup-<版本>.exe`（GPU 版） | 約 1.4 GB | 有 **NVIDIA 顯示卡**的電腦：用顯示卡辨識，又快又準 |
| `Saydown-Setup-<版本>-CPU.exe`（CPU 版） | 約 95 MB | **沒有 NVIDIA 顯示卡**的電腦（一般文書筆電、只有 Intel／AMD 內建顯示的電腦） |

兩個版本的功能一樣，差別只在 GPU 版多帶了約 2 GB 的 NVIDIA 顯示卡函式庫（cuBLAS、cuDNN），讓顯示卡能跑語音辨識。CPU 版用不到顯示卡，所以拿掉這些檔案。

**不知道有沒有 NVIDIA 顯示卡？** 按 `Ctrl`＋`Shift`＋`Esc` 開啟工作管理員 →「效能」，左側有「GPU」項目而且寫著 **NVIDIA** 就選 GPU 版；只有 Intel、AMD 或沒有 GPU 項目就選 CPU 版。
選錯也沒關係：GPU 版在沒有顯示卡的電腦上會自動改用 CPU（只是安裝檔比較大）；CPU 版裝在有 NVIDIA 顯示卡的電腦上，會跳通知建議改裝 GPU 版。兩個版本可以直接互相覆蓋安裝，設定與歷史紀錄都會保留。

安裝時可勾選「建立桌面捷徑」「開機自動啟動」。啟動後右下角系統匣出現 Saydown 圖示，約 15 秒後由灰色變成彩色即可使用。

安裝版的設定、詞庫、歷史紀錄、記錄檔都存在 `%APPDATA%\Saydown`，解除安裝不會刪除。

### 在新電腦上安裝

1. **確認顯示卡驅動**：有 NVIDIA 顯示卡的話，裝好最新的驅動程式。沒有顯示卡可以跳過這步。
2. **安裝 Ollama 與修稿模型**（要修稿才需要，沒有顯示卡建議跳過）：從 [ollama.com](https://ollama.com) 下載安裝 Ollama，裝好後開啟命令提示字元執行：

   ```
   ollama pull qwen3.5:9b
   ```

3. **下載 Saydown**：到 [最新版 Release](https://github.com/allllen001/saydown/releases/latest) 下載安裝檔：有 NVIDIA 顯示卡下載 `Saydown-Setup-<版本>.exe`，沒有就下載 `Saydown-Setup-<版本>-CPU.exe`（怎麼選見上面的表格）。
4. **執行安裝檔**：若出現 Windows SmartScreen 警告，按「其他資訊」→「仍要執行」。依需要勾選「建立桌面捷徑」「開機自動啟動」。
5. **第一次啟動**：Saydown 會自動下載語音辨識模型，請保持網路連線並等它下載完。系統匣圖示由灰色變成綠色後即可使用。
6. **選麥克風**：系統匣圖示按右鍵 →「麥克風」，選擇要用的麥克風。
7. **沒裝 Ollama 的話**：系統匣圖示按右鍵 →「設定」，關掉「修稿」。CPU 版偵測到沒有 Ollama 時，第一次啟動會自動關掉。

啟動時 Saydown 會自己檢查這台電腦缺什麼，右下角跳出 Windows 通知告訴你：

| 通知 | 意思與處理方式 |
|---|---|
| 第一次使用，正在下載語音辨識模型 | 正常，等它下載完；之後會再跳「Saydown 可以用了」 |
| 沒有偵測到 NVIDIA 顯示卡 | 裝了 GPU 版但沒有顯示卡，已自動改用 CPU 辨識，不用處理（只會提醒一次）；想省空間可改裝 CPU 版 |
| 這台電腦有 NVIDIA 顯示卡 | 裝的是 CPU 版，建議改裝 GPU 版，辨識會更快更準 |
| 顯示卡無法使用，改用 CPU 辨識 | 有顯示卡但載入失敗，通常是驅動程式太舊；更新驅動程式後重新啟動 Saydown |
| 沒有安裝修稿用的 Ollama | 要修稿就安裝 Ollama；不需要就到設定關掉「修稿」 |
| 還沒下載修稿模型 | 照通知執行 `ollama pull qwen3.5:9b` |
| 連不上修稿用的 Ollama | 從開始功能表開啟 Ollama |
| 語音辨識模型載入失敗 | 多半是第一次下載時沒有網路；連上網路後重新啟動 Saydown |

錯過的通知可以在 Windows 通知中心找到。

**從舊電腦搬設定（可選）**：先在兩台電腦都結束 Saydown（系統匣右鍵 → 結束），再把舊電腦的 `%APPDATA%\Saydown` 資料夾整個複製到新電腦的同一位置並覆蓋，設定、詞庫和歷史紀錄就會一起搬過去。

### 沒有顯示卡的電腦

Saydown 在沒有 NVIDIA 顯示卡的電腦上也能用，只是功能和速度會有差別：

1. 照上面的步驟安裝，**跳過第 1、2 步**（不用裝顯示卡驅動和 Ollama），第 3 步下載 **CPU 版** `Saydown-Setup-<版本>-CPU.exe`。
2. 第一次啟動時，Saydown 會用 CPU 和較小的語音模型（`small`，約 0.5 GB）辨識。
3. 確認「**修稿**」是關的：CPU 版偵測到沒有安裝 Ollama 時，第一次啟動會自動關掉並跳通知；沒有的話，到系統匣圖示按右鍵 →「設定」關掉。

關掉修稿後，說完話會直接貼上辨識結果：一樣是台灣繁體中文，「嗯、呃」這類贅字會去掉，說「換行」「新段落」也會換行。
實測一段 9 秒的話約 1.6 秒貼上，實際速度依電腦的 CPU 而定。

不修稿時以下功能不能用（都要靠修稿模型）：去掉改口前的說法、整理條列、修正同音錯字、正式語氣／聊天語氣改寫、翻譯、Ask、用說的改寫選取文字、自動學詞。
聊天程式裡句尾不加句號、詞庫提升辨識正確率，這兩項不受影響。

想要辨識更準、可以接受慢一點：把 `config.json` 的 `whisper_model_cpu` 改成 `"medium"`（約 1.5 GB）。
GPU 版也可以在設定的「語音辨識」手動選「CPU」；CPU 版固定用 CPU，這個選項不能改。

### 從原始碼執行

```
git clone https://github.com/allllen001/saydown.git
cd saydown
```

需要先安裝 [Git](https://git-scm.com) 與 [uv](https://docs.astral.sh/uv/)，再建立環境：

```
uv venv .venv --python 3.12
uv pip install --python .venv\Scripts\python.exe -r requirements.txt
```

雙擊 `啟動Saydown.bat`。原始碼版的設定與資料都存在程式資料夾，第一次啟動會用 `config.example.json` 產生 `config.json`。

### 自己打包安裝檔

另外安裝 PyInstaller（`uv pip install --python .venv\Scripts\python.exe pyinstaller`）與 [Inno Setup 6](https://jrsoftware.org/isinfo.php)，再執行：

```
.venv\Scripts\python.exe packaging\build.py
```

預設兩個版本都打包，產生 `dist\Saydown-Setup-<版本>.exe`（GPU 版）與 `dist\Saydown-Setup-<版本>-CPU.exe`（CPU 版）；加 `--gpu` 或 `--cpu` 只打包其中一個。版本號與作者在 `version.py`。

## 用法

| 操作 | 功能 |
|---|---|
| 按住 **右 Alt** 說話，放開 | 聽寫：照你的原話整理，只去贅字、只留改口後的說法、補標點、台灣繁體 |
| 輕按一下 **右 Alt** | 免持錄音，說完再按一下結束（適合長段落，最長 9 分鐘，最後 1 分鐘倒數） |
| 先**反白文字**，再按右 Alt 說「改短一點」「時間改成四點」 | 用說的改寫選取的文字，結果直接取代原文 |
| 按住右 Alt 再按 **Space** | Ask：說出要求（例如「幫我寫一段通知給家長…」），直接產出內容 |
| 錄音中按 **Esc** | 取消，不輸出任何文字 |
| 按住 **F10** | 正式語氣（公務信件、公文） |
| 按住右 Alt 說話時再按一下 **F** | 這一段改用正式語氣，放開右 Alt 照常送出（設定「正式語氣組合」可改成 Tab、Enter 或關掉） |

- 說「換行」「新段落」會換行。
- 說完的文字除了貼到游標位置，也會留在剪貼簿，貼錯地方或想再貼一次，到任何地方按 Ctrl+V 就行（設定的「留在剪貼簿」可關掉，關掉後會還原原本複製的東西）。
- 游標不在輸入框時（例如停在桌面、檔案總管），浮動列會顯示「文字已複製」，提醒你自己按 Ctrl+V 貼上。
- 在 Outlook 會自動用正式語氣；在 LINE、Teams、Discord 等通訊軟體會自動用聊天語氣（句尾不加句號）。
- 系統匣勾選「翻譯成英文」後，右 Alt 說的中文會直接變成英文。

螢幕下方中央的浮動列：紅點與音量條＝錄音中；黃色三點＝處理中。
系統匣圖示顏色：灰＝載入中、綠＝待命、紅＝錄音中、黃＝處理中、紫＝出錯（右鍵 →「開啟記錄檔」查看）。

## 歷史紀錄與詞庫

點系統匣圖示（或右鍵 →「歷史紀錄」）開啟歷史紀錄：可搜尋、複製結果或原始辨識、刪除。
在結果或原始辨識裡反白一個詞 →「加入詞庫」；右上角「詞庫」可新增或刪除常用的人名、專有名詞。詞庫會同時提升辨識和修稿的正確率，改完立即生效。

歷史紀錄存在 `history.db`，只在這台電腦，保留 30 天。系統匣圖示按右鍵可看到目前的版本。

## 設定

系統匣圖示按右鍵 →「設定」：語音辨識用顯示卡或 CPU（預設「自動」）、修稿開關、說完的文字留在剪貼簿、說話鍵（右 Alt、右 Ctrl、F8、F9、滑鼠側鍵、滑鼠中鍵）、正式語氣鍵、正式語氣組合鍵、翻譯成英文、提示音、歷史紀錄保留天數、修稿模型、哪個程式用什麼語氣。改了立即生效，不用重開。
麥克風在系統匣「麥克風」選。

進階設定直接改 `config.json`（系統匣右鍵 →「開啟設定檔」）（同樣改完立即生效）：

- `whisper_device`：`"auto"`（預設，有 NVIDIA 顯示卡就用）、`"cuda"`（顯示卡）、`"cpu"`。
- `whisper_model`／`whisper_model_cpu`：用顯示卡／CPU 時的語音辨識模型，預設 `large-v3`／`small`。
- `polish`：修稿開關，`false` 時完全不用 Ollama。
- `keep_clipboard`：說完的文字留在剪貼簿，預設 `true`。
- `hotkeys`：快捷鍵，例如 `"mouse x2": "cleanup"`（`mouse x1`＝後退鍵、`mouse x2`＝前進鍵、`mouse middle`＝中鍵）。
- `app_tones`：哪個程式用什麼語氣（`formal` 正式、`chat` 聊天、`cleanup` 一般）。
- `dictionary`：詞庫。
- `selection_skip_apps`：不偵測選取文字的程式（預設是終端機與內建終端機的編輯器）。
- `max_seconds`：單次錄音上限（秒），預設 540。
- `log_text`：預設 `false`，記錄檔只記時間和字數，不記錄說話內容。

## 速度

一段 7 秒的話，從放開到貼上約 1.3 秒（辨識約 0.6 秒、修稿約 0.6 秒）。很長的免持錄音（例如 2000 字）修稿約 10 秒。

## 已知限制

- 修稿用的是本機 9B 模型，品質比雲端大模型差一些；正式語氣偶爾會多補一點字。
- 用 CPU 辨識時，準確度比顯示卡的 large-v3 差一些，也不顯示即時預覽（避免和辨識搶 CPU）。
- 修稿模型（Ollama）連不上時，會自動改成一般聽寫：直接貼上未修稿的辨識結果，浮動列顯示一次「未修稿」和原因（沒有安裝 Ollama、Ollama 沒有開啟、沒有下載修稿模型）。這時選取文字再說話，說的話會直接取代選取的文字（可按 Ctrl+Z 還原），不會改寫。每次開始錄音都會重新檢查，Ollama 開起來後下一句就恢復修稿。
- 判斷不出游標在不在輸入框時（例如瀏覽器剛開），一律當作在輸入框，照常貼上，不顯示「文字已複製」。
- 系統管理員權限開啟的視窗裡，快捷鍵無法作用（Windows 的限制）。
- 終端機視窗不偵測選取文字（避免 Ctrl+C 中斷正在執行的程式）。
- 「新段落」有時只換一行，沒有空行。
- 右 Alt 會被 Saydown 占用；需要用到右 Alt 組合鍵時，可在 `hotkeys` 換成別的鍵。

## 版本紀錄

### 1.1.3（2026-10-23）

- 一般聽寫不再改成書面語：沿用你的原話，不自行加「請」「此外」「即可」，一般提問也不再拆成條列；正式語氣維持不變。
- 新增「右 Alt＋F」切換正式語氣：按住右 Alt 說話時再按一下 F，這一段就用正式語氣。

### 1.1.2（2026-10-22）

- 說完的文字預設一律留在剪貼簿，到任何地方都能按 Ctrl+V 再貼一次（設定「留在剪貼簿」可關掉）。
- 修稿模型連不上時自動改成一般聽寫，選取文字說話不再顯示「改寫失敗」；Ollama 恢復後自動恢復修稿。
- CPU 版偵測到沒有安裝 Ollama 時，第一次啟動自動關閉修稿。

### 1.1.1（2026-10-21）

- 游標不在輸入框時（桌面、檔案總管等），說的話留在剪貼簿，到任何地方按 Ctrl+V 貼上。
- 修稿、用說的改寫選取文字、Ask 失敗時，浮動列直接顯示原因：沒有安裝 Ollama、Ollama 沒有開啟、沒有下載修稿模型。

### 1.1.0（2026-10-21）

- 新增 CPU 版安裝檔（約 95 MB），給沒有 NVIDIA 顯示卡的電腦。

- 沒有 NVIDIA 顯示卡也能用：自動改用 CPU 與較小的語音模型；設定可手動選顯示卡或 CPU。
- 設定新增「修稿」開關：關掉後不需要 Ollama，說完直接貼上繁體辨識結果。
- 啟動時檢查缺什麼（顯示卡、Ollama、修稿模型、語音模型下載），用 Windows 通知告訴使用者怎麼處理。

### 1.0.0（2026-10-17）

第一個公開版本：聽寫與修稿、用說的改寫選取文字、Ask、九種語言翻譯、依程式切換語氣、本機歷史紀錄與使用統計、詞庫（可從 Word／PDF 匯入、改字自動學詞）、守護程式自動重開、Windows 安裝檔。
